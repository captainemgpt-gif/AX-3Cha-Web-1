# AI World Signal

Global AI trend intelligence hub website with a neon world-map dashboard, insight reports, news tracker, and Resend-powered contact form.

## Run Locally

1. Copy `.env.example` to `.env`.
2. Fill in `RESEND_API_KEY`, `CONTACT_TO_EMAIL`, and `CONTACT_FROM_EMAIL`.
3. Start the server:

```bash
npm start
```

The site runs at `http://localhost:3000`.
